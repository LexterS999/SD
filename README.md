# Парсер Telegram-каналов и протоколов

Проект собирает профили VLESS / VMess / Trojan / SS / SSR / TUIC / Hysteria из внешних подписок и публичных Telegram-каналов, выполняет жёсткую дедупликацию и формирует итоговый `protocols.txt` только из уникальных профилей.

## Суть проекта

- Telegram-каналы обрабатываются только за последние 7 дней.
- Реестр `protocols.txt` работает как 7-дневное окно:
  - в течение окна новые профили добавляются;
  - дубли запрещены;
  - после 7 дней реестр полностью пересобирается.
- Внедрена комплексная дедупликация:
  - по каноническому виду профиля;
  - по identity-ключу `protocol + ip + port + credential`.
- Разрешены только IPv4 endpoint'ы.
- Запрещены endpoint'ы, где вместо IP используется домен или IPv6.
- Speed-оценка профилей с использованием эталона в 100KB (реальный запрос к
  `SPEED_TEST_URL` подтверждает методику, а массовая проверка каждого из
  десятков тысяч профилей выполняется быстрым TCP-probe, нормализованным под
  тот же эталонный размер — с общим бюджетом времени, чтобы шаг никогда не
  затягивался непредсказуемо).
- Ускоренные профили (>300 KB/s) получают дополнительный вес и поднимаются выше при достаточном базовом скоре.
- Telegram-каналы читаются через быстрое JSON-зеркало, а если оно недоступно —
  автоматически через официальную веб-версию `t.me/s/<channel>` (без API-ключей).
- Настройки параметров через `config.py` на русском языке.

## Основные файлы

- `parser.py` — основной скрипт.
- `config.py` — все настройки с пояснениями на русском.
- `input.txt` — список входных подписок.
- `output/protocols.txt` — итоговый список уникальных профилей.
- `output/protocols_state.json` — внутреннее состояние 7-дневного окна.
- `output/best_channels.txt` — лучшие Telegram-каналы.
- `output/bad_channels.txt` — плохие Telegram-каналы.
- `output/stats.json` — статистика запуска.
- `.github/workflows/parser.yml` — ручной запуск в GitHub Actions: ставит
  зависимости, запускает `parser.py`, коммитит файлы из `output/` (включая
  `protocols_state.json`, обязательный для 7-дневного окна) и их зеркала в
  корне репозитория, публикует артефакт запуска и релиз со статистикой.

## Запуск

```bash
pip install -r requirements.txt
python parser.py
```

Все настройки — в `config.py`, комментарии на русском языке. Результаты
появятся в папке `output/` (и, если `WRITE_MIRROR_FILES_TO_ROOT = True`,
их копии — в корне репозитория).
