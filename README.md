# Парсер Telegram-каналов и протоколов

Автоматизированный парсер для сбора уникальных профилей протоколов (VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC) из внешних подписок и Telegram-каналов.

## 📋 Описание

Проект предназначен для:
- Сбора профилей протоколов из внешних подписок (URL в файле `input.txt`)
- Извлечения Telegram-каналов из этих подписок
- Парсинга протоколов из найденных Telegram-каналов за последние 7 дней
- Оценки качества каналов и профилей по многоуровневой системе
- Удаления дубликатов по IP/домену
- Сортировки результатов по качеству

## 🔧 Поддерживаемые протоколы

- **VLESS** - vless://
- **VMess** - vmess://
- **Trojan** - trojan://
- **Shadowsocks** - ss://
- **Hysteria/Hysteria2** - hysteria://, hysteria2://
- **TUIC** - tuic://

## 📁 Структура проекта

```
├── parser.py              # Основной скрипт парсера
```

## 🚀 Быстрый старт

### Локальный запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Отредактируйте `input.txt` и добавьте ваши подписки:
```
https://example.com/sub1
https://example.com/sub2
```

3. Запустите парсер:
```bash
python parser.py
```

4. Проверьте результаты:
- `protocols.txt` - уникальные профили, отсортированные по качеству
- `best_channels.txt` - лучшие Telegram-каналы
- `stats.json` - статистика

### Запуск через GitHub Actions

Workflow настроен на:
- **Автоматический запуск** каждые 3 часа (в 00:00, 03:00, 06:00, 09:00, 12:00, 15:00, 18:00, 21:00 UTC)
- **Ручной запуск** через вкладку Actions → "Парсер Telegram-каналов и протоколов" → "Run workflow"

## 📊 Система оценки качества

### Для Telegram-каналов:

| Фактор | Вес | Описание |
|--------|-----|----------|
| Количество профилей | 25% | Логарифмическая шкала от максимума |
| Разнообразие протоколов | 20% | До 6 различных протоколов |
| Частота обновлений | 20% | Актуальность контента (7 дней) |
| Валидность конфигураций | 20% | Количество рабочих конфигов |
| Репутация домена | 15% | Проверка на подозрительные домены |

### Для профилей протоколов:

| Фактор | Баллы | Описание |
|--------|-------|----------|
| Базовая оценка | 50 | Стартовое значение |
| Наличие IP | +10 | Если IP определен |
| Стандартный порт | +5 | 443, 80, 8443, 8080, 22 |
| Надежный домен | +10 | Нет подозрительных доменов |
| Метаданные | до +15 | Дополнительные параметры |

## ⚙️ Настройка

### Добавление подписок

Откройте `input.txt` и добавьте URL подписок:
```txt
https://example.com/sub1
https://raw.githubusercontent.com/user/repo/main/config.txt
https://github.com/user/repo/raw/main/config.txt  # Автоматически конвертируется
```

### Изменение периода парсинга Telegram

В файле `parser.py` измените параметр `days` в методе `process_telegram_channels`:
```python
await self.process_telegram_channels(days=7)  # Изменить число дней
```

### Настройка расписания GitHub Actions

В `.github/workflows/parser.yml` измените cron-выражение:
```yaml
schedule:
  - cron: '0 */3 * * *'  # Каждые 3 часа
  # Примеры:
  # '0 0 * * *' - каждый день в полночь
  # '0 */6 * * *' - каждые 6 часов
  # '0 9 * * 1-5' - каждый будний день в 9:00
```

## 🔍 Особенности

- **Асинхронная обработка** - быстрая работа с большим количеством URL
- **Автоматическая конвертация GitHub URL** - github.com → raw.githubusercontent.com
- **Дедупликация** - удаление дубликатов по IP/домену и порту
- **Логирование** - подробный лог всех операций
- **Обработка ошибок** - продолжение работы при ошибках отдельных URL

## ⚠️ Важные замечания

1. **Telegram API ограничения** - некоторые каналы могут быть недоступны через публичные API
2. **Rate limiting** - при большом количестве подписок возможны временные блокировки
3. **Актуальность данных** - профили устаревают, рекомендуется регулярное обновление
4. **Приватные каналы** - парсер работает только с публичными Telegram-каналами

## 🛠️ Требования

  - beautifulsoup4 >= 4.12.0
